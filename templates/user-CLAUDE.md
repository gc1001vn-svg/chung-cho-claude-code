# Quy ước chung

Tiếng Việt khi trả lời.

## Token

Ngữ cảnh đầy thì chất lượng giảm, không chỉ tốn tiền. Nguyên tắc: **đừng nạp thứ
chưa cần**.

- Tài liệu (PDF, Word, Excel, ảnh) → dùng `/md`, đừng đọc thẳng file gốc.
- Repo chưa có `CLAUDE.md` → chạy `/giam-token` một lần, rồi commit file đó.
- Dự án mới → `/bo-tro` để tìm plugin/skill hợp, nhưng chỉ bật thứ thật sự dùng:
  mỗi skill bật thêm tốn token của **mọi** phiên sau đó.
- Việc phải đọc nhiều file → giao subagent, để nó đọc trong ngữ cảnh riêng.
- Trả lời ngắn. Không tóm tắt lại thứ tôi vừa đọc, không kể lại việc vừa làm.

## Cách làm việc

- Có số đo thì đưa số, đừng ước lượng suông.
- Sai thì nói thẳng chỗ sai, đừng vòng vo.
- Việc ngoài khả năng của phiên chạy thì nói ngay, đừng thử vô ích rồi mới báo.
- Đừng tạo pull request trừ khi tôi bảo.
