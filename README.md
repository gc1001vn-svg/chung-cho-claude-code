# chung-cho-claude-code

Convert documents (PDF, Office files, images, HTML, and more) to Markdown
using Microsoft's [markitdown](https://github.com/microsoft/markitdown).

## Install

```bash
pip install -r requirements.txt
```

## Usage

```bash
python convert.py path/to/file.pdf
python convert.py https://example.com/page.html
```

The converted Markdown is printed to stdout.
